# FindVision AI

실종 재난문자에 포함된 인상착의를 AI가 분석하고,  
그 정보를 바탕으로 **참고용 인상착의 이미지**를 생성하는 학교 프로젝트입니다.

> 생성된 이미지는 실제 얼굴 복원이나 신원 확인용이 아닙니다.  
> 재난문자에 기재된 복장·체형·소지품 등을 쉽게 이해하기 위한 참고용 시각화입니다.

## 주요 기능

- 실종 재난문자 입력
- 나이 / 성별 / 키 / 체형 / 복장 / 소지품 자동 추출
- 추출된 정보 구조화
- 인상착의 참고 이미지 생성

## 사용 기술

- Python
- Streamlit
- OpenAI API

## 실행 방법

### 1. 저장소 다운로드

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd findvision-ai
```

### 2. 패키지 설치

```bash
pip install -r requirements.txt
```

### 3. 환경변수 파일 생성

`.env.example`을 복사해서 `.env` 파일을 만듭니다.

```env
OPENAI_API_KEY=본인의_API_KEY
TEXT_MODEL=gpt-5-mini
IMAGE_MODEL=gpt-image-1
```

`.env` 파일은 `.gitignore`에 포함되어 있으므로 GitHub에 업로드되지 않습니다.

### 4. 실행

```bash
streamlit run app.py
```

브라우저에서 표시되는 주소로 접속합니다.

## 예시 입력

```text
실종자 김OO(남, 72세), 키 170cm, 마른 체형,
흰색 반팔티, 검은색 바지, 회색 모자와 검은 운동화 착용
```

## 프로젝트 흐름

```text
재난문자 입력
    ↓
AI 인상착의 분석
    ↓
구조화된 특징 정보
    ↓
이미지 생성 프롬프트
    ↓
참고 이미지 생성
```

## 주의사항

실종 재난문자에는 얼굴 세부 정보가 없는 경우가 많습니다.
따라서 본 프로젝트는 실제 얼굴을 정확하게 재현하는 시스템이 아니라,
**문자 기반 인상착의 시각화 보조 시스템**을 목표로 합니다.
