# FindVision AI

실종 재난문자에 포함된 인상착의 정보를 AI가 분석하고, 해당 정보를 바탕으로 전신 참고 이미지를 생성하는 웹 서비스입니다.

> 생성된 이미지는 실제 실종자의 얼굴을 복원하거나 신원을 확인하기 위한 사진이 아닙니다.  
> 재난문자에 적힌 인상착의를 빠르고 쉽게 이해하기 위한 참고 이미지입니다.

---

## 1. 문제 정의

기존 실종 재난문자는 이름, 성별, 나이, 키, 몸무게, 복장 등의 정보가 문장으로 제공됩니다.

하지만 긴 문장을 읽고 실종자의 모습을 바로 떠올리기는 어렵습니다. 특히 상의, 하의, 신발, 모자와 같은 주요 특징을 빠르게 파악하기 어렵다는 문제가 있습니다.

FindVision AI는 다음 문제를 해결하기 위해 제작했습니다.

- 실종 재난문자에서 주요 인상착의 정보 자동 추출
- 상의, 하의, 신발, 모자 등의 정보 분류
- 분석된 내용을 바탕으로 전신 참고 이미지 생성
- 생성된 이미지가 입력 조건과 일치하는지 AI로 검수
- 이미지 안에 의미 없는 글자가 생성되는 문제 방지
- 분석 결과를 한국어로 표시

## 2. 시스템 아키텍처

```text
사용자
  ↓
실종 재난문자 입력
  ↓
Streamlit 웹 애플리케이션
  ↓
텍스트 분석 AI
  ├─ 이름
  ├─ 성별
  ├─ 나이
  ├─ 키 / 몸무게
  ├─ 체형
  ├─ 상의 / 하의
  ├─ 신발
  ├─ 모자 종류 / 색상
  └─ 기타 특징
  ↓
이미지 생성 AI
  ↓
전신 참고 이미지 생성
  ↓
Vision AI 자동 검수
  ├─ 상의 확인
  ├─ 하의 확인
  ├─ 신발 확인
  ├─ 모자 종류와 색상 확인
  ├─ 전신 표시 여부 확인
  └─ 이미지 내부 글자 확인
  ↓
조건 불일치 시 최대 3회 재생성
  ↓
최종 이미지와 한국어 인상착의 출력
```

## 3. 사용 기술 스택

| 구분 | 사용 기술 |
|---|---|

## 4. 주요 기능

- 한국어 실종 재난문자 입력
- 이름, 성별, 나이, 키, 몸무게 자동 분석
- 상의, 하의, 신발, 모자 정보 자동 분석
- 캡모자, 비니, 벙거지 등 모자 종류 구분
- 모자 색상 구분
- 전신 참고 이미지 생성
- 외국인이라고 명시되지 않으면 한국인을 기본 인물로 설정
- 생성된 이미지 자동 검수
- 조건 불일치 시 최대 3회 자동 재생성
- 이미지 안에 글자, 숫자, 문구가 들어가지 않도록 제한
- 분석 결과와 오류 메시지를 한국어로 표시

## 5. 실행 방법

### 5-1. 저장소 다운로드

```bash
git clone https://github.com/rnwkdns11-collab/findvision-ai.git
cd findvision-ai
```

### 5-2. 필요한 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 5-3. Cloudflare API 설정

프로젝트 폴더 안에 다음 파일을 생성합니다.

```text
.streamlit/secrets.toml
```

다음 내용을 입력합니다.

```toml
CLOUDFLARE_ACCOUNT_ID = "본인의 Cloudflare Account ID"
CLOUDFLARE_API_TOKEN = "본인의 Cloudflare API Token"
```

Cloudflare API Token은 외부에 공개하거나 GitHub에 업로드하면 안 됩니다.

### 5-4. 프로그램 실행

```bash
streamlit run app.py
```

실행 후 브라우저에서 다음 주소로 접속합니다.

```text
http://localhost:8501
```

Streamlit Community Cloud에서는 GitHub 저장소를 연결하고 Secrets에 다음 값을 입력하면 됩니다.

```toml
CLOUDFLARE_ACCOUNT_ID = "본인의 Cloudflare Account ID"
CLOUDFLARE_API_TOKEN = "본인의 Cloudflare API Token"
```

## 6. AI 사용 내역

### 텍스트 분석 AI

사용자가 입력한 실종 재난문자를 분석하여 다음 정보를 추출합니다.

- 이름
- 성별
- 나이
- 키
- 몸무게
- 체형
- 상의
- 하의
- 신발
- 모자
- 모자 종류
- 모자 색상
- 소지품 및 액세서리
- 머리 특징
- 기타 특징

외국인 또는 외국 국적이라는 내용이 없으면 한국인을 기본 인물로 설정합니다.

### 이미지 생성 AI

추출한 인상착의 정보를 이미지 생성용 프롬프트로 변환하여 전신 참고 이미지를 생성합니다.

이미지 생성 시 다음 조건을 적용합니다.

- 한 명의 인물만 생성
- 머리부터 발끝까지 전신 표시
- 상의, 하의, 신발, 모자 조건 반영
- 단순하고 밝은 배경 사용
- 이미지 안에 글자, 숫자, 문구를 넣지 않도록 제한
- 실제 얼굴을 임의로 복원하지 않도록 제한

### 이미지 검수 AI

생성된 이미지를 Vision AI가 다시 확인합니다.

검수 항목은 다음과 같습니다.

- 상의 색상과 종류
- 하의 색상과 종류
- 신발 색상과 종류
- 모자 종류와 색상
- 전신 표시 여부
- 이미지 내부 글자 포함 여부

입력 조건과 일치하지 않으면 최대 3회까지 이미지를 다시 생성합니다.

## 7. AI 사용 시 주의사항

- 생성형 AI는 모든 조건을 항상 정확하게 반영하지 못할 수 있습니다.
- 생성된 얼굴은 실제 실종자의 얼굴이 아닙니다.
- 결과 이미지는 신원 확인이나 수사 증거로 사용하면 안 됩니다.
- 생성된 이미지는 인상착의를 이해하기 위한 참고 자료입니다.
- 실제 사용 전 사람이 결과를 다시 확인해야 합니다.
